# First REST API

## Project Description

This project is a REST API application developed using Spring Boot.

The application allows users to manage products using full CRUD operations:
- Create Product
- Read Product
- Update Product
- Delete Product

The project uses:
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Swagger OpenAPI

All endpoints were tested successfully using Swagger UI and H2 Database Console.

---

# Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Swagger UI
- Maven
